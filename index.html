Weekly sales

How the numbers work. The 12-week average is the average of the last 12 weeks of sales (the “Avg - 3 Months” column in the workbook). “Last year” is the same week 52 weeks earlier. Every change is measured against the earlier figure, so +10% vs last year means 10% more than last year’s week. Butler is shown excluding DRYZ, with DRYZ on its own line; All stores includes both.

How do I get a token?
  1. On GitHub, click your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pick this dashboard’s repository.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Choose an expiry (a year is fine), generate it and paste it here.

The repository and token are saved in this browser only.
